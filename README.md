# 💖 Shareable

**Shareable** is a platform built for creators and their communities. It allows creators to **monetize their content**, manage their **supporters**, and offer **exclusive benefits** through subscriptions and donations.

Whether you're a musician, writer, podcaster, or digital artist, Shareable helps turn your passion into a sustainable income stream.

---

## 🚀 Features

- Creator profiles and support tiers  
- PayPal integration for one-time and recurring support  
- Analytics dashboard (powered by Chart.js)  
- Messaging and updates for supporters  
- Email notification system using EmailJS  
- Protected content for paying members  
- Clean, responsive UI with Bootstrap  
- Role-based access for creators and supporters  

---

## 🌍 Mission

At Shareable, we’re committed to giving creators the tools they need to thrive — without taking a cut of their creative freedom.  
We empower creators to build meaningful connections and communities, all while maintaining control over their content.

## 🛠️ Tech Stack

### Frontend
- React, React Router, React-Bootstrap  
- Redux Toolkit for state management  
- Chart.js + React Chart.js 2  
- PayPal SDK for secure payments  
- EmailJS for transactional emails  
- Font Awesome, React Icons  

### Backend
- Django (Python)  
- SQLite (development DB)  
- REST API architecture
